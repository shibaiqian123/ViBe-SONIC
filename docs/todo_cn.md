# 发布后的实现待办事项

仅涉及功能实现和基础设施工作；以下事项均不影响当前版本发布。

## 高收益改进

- [ ] 使用上游扩展接口替代全局 MJLab 运行时补丁，支持多片段动作命令、`--agent initial` 和仿真器配置。
- [ ] 提供显式、可重复调用且不会产生重复副作用的 `orcs.register()` API，返回结构化的注册报告；MJLab 入口仅负责调用该 API。
- [ ] 延迟注册任务配置工厂，避免在插件发现阶段构建全部配置并检查数据集。
- [ ] 对生成资产和动作数据的格式约定进行版本管理。在每份生成的数据集中记录数据结构版本、生成器 Git 提交 SHA、源数据出处、坐标约定和输入信息；拒绝使用过时缓存，并提供重新生成命令。

## 稳健性增强

- [ ] 用显式的 `RuntimeLayout` 对象替代导入时确定的路径常量，支持嵌入其他项目、独立仓库和 wheel 安装三种布局。
- [ ] 为 UOLM、PerLoco、Dodge 和 SMPL 任务各添加一个小型无界面的重置/仿真步进冒烟测试，以发现配置、传感器、观测和模型加载方面的问题。
- [ ] 添加持续集成（CI），覆盖 Ruff 检查、接口约定测试、干净环境中的 wheel 安装、命令行入口、任务注册，以及独立和嵌入式项目布局。
- [ ] 为 `deps.lock` 定义可校验的数据结构，并提供一个统一命令，报告代码、生成数据及资产生成器相对于预期版本的偏离。

## 完善与整理

- [ ] 使用结构化、可统一关闭的日志，替代分散的诊断打印。
- [ ] 为注册、运行时布局、资产、智能体和数据集格式约定定义一组精简、稳定的公共 API；将任务实现模块视为内部接口。
- [ ] 将源码注释中关于历史实现过程的叙述移到简短的决策记录中，仅在代码旁保留当前仍需遵守的约束。
